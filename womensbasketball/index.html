Each line is one player's mapped assists to one teammate, from ESPN's play-by-play, where an assisted basket names the passer and the scorer. In some games the play-by-play has fewer assists than the box score, so every game shows both counts. Hub and authority are HITS scores on the network through the selected game: a player's hub score weights each mapped assist by the receiver's authority score, and authority weights each mapped assisted basket by the passer's hub score. Each team's scores are scaled to unit length within that network. Team entropy is the Shannon entropy of each player's share of the assists made, divided by log2 of the number of players on the map, so 1 means every player makes the same number of assists. The trend lines run 0 to 1. Dates are Pacific time.
